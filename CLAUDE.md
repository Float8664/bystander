# Project Context

## Продукт
Образовательный веб-инструмент — интерактивный калькулятор,
иллюстрирующий эффект свидетеля и диффузию ответственности (Darley & Latané, 1968)
на примере многоквартирных домов. Пользователь вводит параметры жилья
(число соседей N, расположение квартиры, тип дома, время суток, серьёзность
ситуации, культурный контекст) и получает иллюстративную вероятность
P = 1 − (1 − p_инд)^N, где p_инд корректируется мультипликативными
модификаторами и убывает с ростом N. Цель — обучение и исследовательская
визуализация, не предсказание реальных событий.

## Стек
Next.js (App Router) + TypeScript + Tailwind + shadcn/ui, графики на Recharts,
деплой на Vercel. Бэкенда нет (до отдельного решения). Состояние калькулятора —
в URL-параметрах для шаринга. PWA.

## Архитектурные правила (не нарушать)
1. Вся математика модели живёт ТОЛЬКО в `src/lib/model` — чистые функции, без React.
   В компонентах формул нет никогда.
2. У модели есть юнит-тесты (Vitest). Любое изменение коэффициентов или формулы —
   с тестом на инвариант (P в [0,1], поведение по N) и/или golden-тестом на сценарий.
3. Сайт статический; интерактивен только компонент Calculator ("use client").
   Не размазывай server/client-границы по коду.
4. Каждое решение по значению модификатора фиксируй в `docs/model-rationale.md`
   с обоснованием и, по возможности, ссылкой на источник.
5. Не добавляй зависимости без необходимости и объяснения зачем.

## Дисциплина
- Делай маленькие изменения и предлагай коммит после каждого рабочего шага.
- В конце сессии дописывай в `docs/decision-log.md`, что изменилось и почему.
- Код доступный: подписи для скринридеров, клавиатурная навигация.

## Интеллектуальная честность
В интерфейсе и текстах разделяй установленный психологический феномен
(со ссылкой на исследования) и иллюстративную параметризацию этого инструмента.
Не подавай вычисленную вероятность как эмпирически валидированный прогноз.
